# Security policy

Scanisaur is designed to read warehouse metadata only: it never reads table data and never runs the queries it checks. A bug that breaks either promise is a security issue.

## Reporting a vulnerability

Please report vulnerabilities privately, not in a public issue: use GitHub's [private vulnerability reporting](https://github.com/tjslezak/Scanisaur/security/advisories/new) or email [dev@scanisaur.com](mailto:dev@scanisaur.com). Include steps to reproduce and the version affected.

## Supported versions

Scanisaur is pre-release. Security fixes go into the latest release only.
